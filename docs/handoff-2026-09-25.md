## Traps met this session

- **A route that never fires reads exactly like a product that never acted.**
  Count the route beside an independent witness (page `request` events,
  Resource Timing) before deciding which one is silent.
- **A lint's exemption is a claim.** `check-routes` believed cross-origin
  requests never reach the worker; one probe showed otherwise.
- **A wait on the wrong decision point makes a red for the wrong reason.** The
  D122 red first failed at its own wait (a held copy opens with no card); make
  the red fail at the assertion it exists for before believing it.
- **A test's forge that goes around a lock races the product's locked writes.**
  Wait for the state the next step needs (here, a link under the forged key),
  not for the write.
- **`ci-verdict.mjs` gives counts per shard, not names.** The failing and flaky
  tests come from `gh run view <id> --log`; read them before believing any list.
- **Shell backslashes collapse** in inline `node -e` paths built from `$TEMP`;
  use Edit, or a path with forward slashes.
