  it in the same scope as a later `const` of the same name, and nothing in
  `npm run typecheck` would say so; only the vite build would. Name new

  running.

  reaches the opener's tests only after `npm run build` (D30). Build, run, restore
  from a copy, build again.
- **`tsc` on one test file also checks `src/` under the wrong settings.** Filter
  its output to `^tests/`; the `src/` errors it prints are not the test's.
