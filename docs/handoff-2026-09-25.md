## Traps met this session

- **A probe changes the timing it measures.** One extra `evaluate` before the
  close made 619 pass 12 of 12; the state it read still showed the miss. Read
  what the probe saw, not whether the test passed.
- **Force the losing order to get a red on the cause.** Holding the host's save
  message made a coin flip into 8 of 8, and made the fix's wait provably
  load-bearing.
- **A witness that can only say yes proves nothing.** `confirmedInStore` was
  shown reading false first on every run before it was trusted.
- **A branch that reads as a guard may be unreachable.** "Published by somebody
  else" had no test and could not fire; the attempt to make it red found D126.
- **A source check fails first where it is meant to.** The first proof of
  `arrival-refusals` failed on a missing helper, not on the scan; reordered and
  proven again.
- **Backticks inside a double-quoted `node -e` run as shell commands** and
  silently drop the code spans. Use Write for prose with backticks.
- **Compare a rare failure against the baseline at n=48, not n=16.** 0/16
  against 2/16 looked like a regression; 1/48 against 2/48 is not.
