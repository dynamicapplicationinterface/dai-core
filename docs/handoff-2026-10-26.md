### Decided here, to confirm

- **`@noble/ed25519` stays a devDependency.** Item 1 moved it beside
  `@sqlite.org/sqlite-wasm` and `fflate`; the push gate refused it:
  `tests/packaging.spec.ts`, "keeps its runtime dependencies to what the
  format needs", holds the published library to exactly those two ("Two is
  the budget: the zip implementation and the database engine"). Nothing in
  `src/` imports it; only the opener does (`keychain-key.ts`), and the
  opener's build bundles it, so an installed copy of the library never needs
  it, and as a dependency it would arrive in every installer's tree. Item 1
  is reverted (`1a7e7cd3`), not the guard changed. Ruling wanted: keep it a
  devDependency (the opener is built from this repository), or raise the
